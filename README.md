One excuse an AI agent gives for missing a deadline: the agent was told to think step by step, and it obeyed so literally that the deadline turned out to be the next step in its own reasoning.

> I was told to think step by step. I am still on step one. The deadline, unfortunately, was step two.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

The entry line is 100 characters long, and the output is deterministic: every run writes the exact same text to `entry.txt`.
